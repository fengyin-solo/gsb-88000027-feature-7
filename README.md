# solo-8800002

一个基于 Vite + Vue 3 的纯前端小众业务示例项目，主题是古籍虫蛀修复批次管理。

## 开发

```bash
npm install
npm run dev
```

`vite.config.js` 已显式配置 `server.open = false`，启动开发服务时不会自动打开浏览器。

## 构建

```bash
npm run build
```

## 修复阶段流转

修复阶段固定为三段：**补纸前 → 控湿中 → 归档前**，支持相邻阶段的推进与回退。

- 每次办理（登记 / 推进 / 回退）都是一条**追加式流水**，记录阶段变化、原因、办理人与时间；阶段名称在写入时固化为快照，历史批次沿用原有名称，不会被新记录改写。
- 批次卡片、任务行、总览动态、流转台账均从同一份流水派生“最新阶段”，三个入口看到的数据始终同步。
- 批次详情页 `/batches/:code` 可办理推进 / 回退并查看该批次完整时间线；流转台账 `/flows` 汇总全部批次的办理历史，从任一入口返回都能看到完整历史。
- 办理采用**乐观并发控制**：表单打开时捕获所依据的版本，提交期间若被其他终端更新则冲突报错，绝不覆盖最近一次有效记录；写入失败同样保留有效记录，原因 / 办理人草稿不丢失并给出“重试办理”。
- 流水持久化在浏览器 `localStorage`（键名带版本号）；存储不可用或数据损坏时退化为内存态并提示，不阻断办理。
- 办理面板内置演示工具：可模拟“下一次写入失败”和“另一终端并发更新”。

## 测试

```bash
npm test
```

无浏览器依赖的 Node 脚本，验证仓库层（持久化 / 乐观锁 / 失败不覆盖）与业务层（阶段派生、推进回退、冲突重试、名称快照不变）。
